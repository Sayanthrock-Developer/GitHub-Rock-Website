GitHub, made mobile.

Native Android developer control centre. Sign in, browse repos, track issues & PRs, monitor Actions, generate build workflows, download artifacts, and inspect APKs — in one clean Compose app.

Get the app View source
Android 10+ OAuth Device Flow Encrypted tokens Apache-2.0

What you can do

Everyday use

  • Sign in with GitHub (Device Flow)
  • Browse & search repositories
  • View issues, PRs, and Actions
  • Download release assets
  • Inspect APKs (permissions, signing, hash)
  • Light / dark / true black themes

Android developers

  • Auto-detect Android projects
  • Generate safe GitHub Actions workflows
  • Open PRs with the workflow
  • Trigger builds & watch progress
  • Download built APKs into the app

Extras

  • Guest mode (public repos)
  • Isolated Demo mode
  • Quick links to 45 official GitHub pages
  • Notifications, Codespaces, Copilot, Settings…

Platforms

PlatformWhat you get

Security

  • Only the public OAuth Client ID ships in the app
  • Tokens stored encrypted with Android Keystore
  • No passwords ever requested
  • Release APKs verified against pinned signing certificate
  • Demo data fully isolated from real accounts
